# Character Studio

Браузерный 3D-редактор персонажа на Three.js. Откройте опубликованную страницу GitHub Pages или запустите локально:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000/. Для загрузки Three.js и шрифта требуется интернет. Модели и лицензии находятся в `assets/`; исходная пользовательская модель — `Base.fbx`.

Публикация настроена через GitHub Actions и GitHub Pages; в настройках репозитория источник Pages должен быть установлен в **GitHub Actions**.
